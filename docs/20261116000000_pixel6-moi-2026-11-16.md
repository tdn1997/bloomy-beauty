# Pixel_6 tạo lại sau nâng cấp macOS — 16/11/2026

Đã tạo lại một AVD `Pixel_6` theo yêu cầu người dùng. Không khôi phục dữ liệu
ứng dụng của các máy ảo cũ đã mất.

## Cấu hình

- Tên hiển thị: **Pixel 6**; tên AVD: `Pixel_6`.
- Image: `system-images;android-35;google_apis;arm64-v8a`, Android 15/API 35,
  Google APIs, ARM64 cho Apple Silicon. Image này có Google APIs, không có ứng
  dụng Play Store.
- Màn hình 1080 × 2400, mật độ 420 dpi; 4 CPU; RAM emulator tự tăng lên 2560 MB;
  phân vùng dữ liệu 6 GiB theo mức tối thiểu emulator áp dụng khi tạo lần đầu.
- Cấu hình tại `~/.android/avd/Pixel_6.ini` và
  `~/.android/avd/Pixel_6.avd/config.ini`; target `android-35`.
- Android Emulator 37.2.13.0; máy chủ macOS 27.2.1, Apple M1 Pro.

## Mở lại máy ảo

Mở **Device Manager** trong Android Studio và chạy **Pixel 6**, hoặc:

```sh
~/Library/Android/sdk/emulator/emulator -avd Pixel_6
```

Không chạy lệnh trên nếu Pixel_6 đã mở. Kiểm tra máy đang chạy:

```sh
~/Library/Android/sdk/platform-tools/adb devices
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 emu avd name
~/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell getprop sys.boot_completed
```

Serial có thể khác nếu có thiết bị khác; lấy serial thực tế từ `adb devices`.

## Những gì đã xử lý

1. Thư mục AVD cũ trống. Image API 35/36 còn metadata nhưng mất `system.img`.
   Đã cài lại đúng image API 35 qua SDK Manager.
2. Thử image API 37 có sẵn: command-line tools 9.0 tạo nhầm `target=android-0`
   và tên `<build>`. Sửa target/tên giúp máy khởi động, nhưng các ca UI cũ lỗi
   `NoSuchMethodException: android.hardware.input.InputManager.getInstance`.
   14 ca repository Mua lại đơn cũ vẫn đạt trên API 37.
3. Chuyển sang API 35 cho bộ kiểm thử hiện có. Xóa AVD API 37 mới tạo và tạo
   lại cùng tên `Pixel_6`; cuối cùng chỉ giữ một AVD.
4. Emulator yêu cầu khoảng 7,2 GiB trống để tạo phân vùng dữ liệu. Đã gỡ image
   API 37 không còn AVD sử dụng để lấy lại khoảng 5 GiB; không xóa dữ liệu cá
   nhân hoặc cache toàn máy. Có thể cài lại image API 37 bằng SDK Manager sau.
5. Kiểm thử tính năng và hồi quy: xem [hồ sơ Mua lại đơn cũ](kiem-thu/reorder-2026-11-16/README.md).

Nếu build Gradle gặp lỗi `25.0.4`, đó là JDK 25 không tương thích với Gradle
hiện tại, tách biệt với AVD. Dùng JDK 21 và lệnh trong hồ sơ kiểm thử; không cần
tạo lại máy ảo vì lỗi Java đó.
